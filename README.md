## 📖 Executive Summary & Concept

**Portifolio — The Series** is a streaming-inspired interactive personal portfolio application engineered for **Erick Lusungu Msola**: Bachelor of Business Information Technology graduate from the University of Dar es Salaam (UDSM), IT Systems Specialist, and Finance Associate at PricewaterhouseCoopers (PwC).

Traditional portfolios are static resumes. **The Series** reimagines the professional journey as an episodic streaming entertainment experience:
- Every career milestone and educational placement is serialized into **Seasons & Episodes**.
- All verified GitHub repositories and open-source applications are presented as premier **Original Productions**.
- Visitors select their own narrative path via a Netflix-style **"Who's Watching?" profile selector** that adapts the content hierarchy to their role.

## 🎬 Key Features

### 1. Theatrical Opening Title Sequence
- Anamorphic letterbox aspect ratio bars with authentic studio title card (*"AN ERICK MSOLA ORIGINAL"*).
- Hardware-accelerated cinematic reveal zoom into high-resolution WebP rim-lit portrait.
- Keyboard-accessible skip handler (`Enter` or `Esc`) and session-aware storage to prevent repetitive playback.

### 2. High-Impact Billboard Hero
- Mouse & pointer-driven 3D parallax tilt with depth layering across floating status chips.
- Atmospheric volumetric glow particles and cinematic light streaks.
- Quick **"▶ Play Intro"** trigger running an interactive highlight reel with slide pauses and arrow key navigation (`←`, `→`).

### 3. Pinned "Originals" Production Showcase
- Desktop pinned horizontal scrub experience that glides sideways as the user scrolls downward.
- Responsive fallback to native momentum touch swipe on mobile devices.
- Detailed modal backdrop featuring custom SVG key-art motifs (`shield`, `flow`, `tenants`) reflecting each project's architecture.

### 4. Interactive Screenplay Resume & PDF Engine
- Live responsive resume sheet reflecting Erick's official CV document with 1:1 section fidelity.
- Built-in full-screen modal featuring PDF embed for desktop viewports and direct PDF download action.
- Live personal references, verified credentials, and legal declaration statement.

## ⚡ Quick Start & Local Setup

### Prerequisites
- **Node.js**: `v18.0.0` or higher
- **npm**: `v9.0.0` or higher (or `pnpm` / `yarn`)
- **Git**

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Msollajr5/Portifolio.git
cd Portifolio

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

> 🌍 Vite will start the development server at **`http://localhost:5173/Portifolio/`** with instant Hot Module Replacement (HMR).

## 🚀 Build & Production Deployment

To compile an optimized production build:

```bash
# Build TypeScript and bundle static assets with Vite
npm run build

# Preview the production build locally
npm run preview
```

### GitHub Pages Deployment
The repository includes a production-ready GitHub Actions workflow at [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml). Any push to the `main` branch automatically:
1. Validates TypeScript types and lint checks.
2. Compiles production assets into `dist/`.
3. Ensures `.nojekyll` and `404.html` routing fallbacks are generated.
4. Deploys the static bundle seamlessly to **GitHub Pages**.

## ⚙️ Content Management & Customization

The platform uses a strict **Single Source of Truth** architecture. All content, projects, experience entries, and contact links are centralized in:

📂 **[`src/data/portfolio.ts`](src/data/portfolio.ts)**

| Entity to Modify | Configuration Object | Impact on UI |
|---|---|---|
| **Identity & Socials** | `profile` | Navbar, Hero title, resume sheet, contact buttons, LinkedIn/GitHub links |
| **GitHub Projects** | `projects: Project[]` | Originals horizontal rail, detail modals, resume project list, project counts |
| **Skill Universe** | `skillCategories`, `skillEvidence` | Interactive genre tabs, primary skill highlights, hover evidence |
| **Work Experience** | `experience: Job[]` | "The Pilot" stats, resume sheet timeline, organization metrics |
| **Career Timeline** | `seasons: Season[]` | "My Journey" episodic timeline (S01, S02, S03), episode cards |
| **Resume & Qualifications**| `education`, `certifications`, `referees` | Resume sheet, full-screen PDF modal, referee contact block |
| **Persona Narratives** | `viewerProfiles` | Profile switcher orders for Recruiter, Technical, and Executive modes |

## ♿ Accessibility & Performance Highlights

- **Reduced Motion Support**: Strictly honors `prefers-reduced-motion: reduce`. Disables heavy physics scrolls, particle simulations, cursor springs, and skips directly past opening cinematic sequence.
- **Progressive Input Detection**: Touch devices automatically receive swipeable native rails and touch targets; desktop hardware receives magnetic buttons and custom cursor tracking.
- **Modern Media Pipeline**: Portraits are served in modern **WebP** formats with responsive `srcset` resolutions (`420w`, `720w`, `1100w`) to minimize bandwidth consumption.
- **Keyboard Navigation**: Full `Escape`, `Enter`, and Arrow key navigation across modal windows, slideshow reels, and profile switchers.
